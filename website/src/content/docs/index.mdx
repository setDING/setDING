## Warum setDING?

<CardGrid>
  <Card title="Für die Bühne gemacht" icon="rocket">
    Live-Modus im Vollbild, der Bildschirm bleibt an. Umblättern per Tippen, Wischen
    oder mit einem Bluetooth-Fusspedal – die Hände bleiben am Instrument.
    Funktioniert komplett offline.
  </Card>
  <Card title="Sets für die ganze Band" icon="list-format">
    Songs per Drag & Drop zum Set zusammenstellen, Pausen und Notizen einfügen,
    Tonart und Ablauf pro Song festlegen. Alle bekommen das Set auf ihr Gerät, und
    setDING zeigt, wann es offline bereit ist.
  </Card>
  <Card title="Jede und jeder sieht es auf ihre Art" icon="setting">
    Transponieren mit einem Tipp, Kapodaster, Schriftgrösse, B- oder H-Notation oder
    Nashville-Zahlen. Persönliche Notizen ändern den Song nie für den Rest der Band.
  </Card>
  <Card title="Eure Songs, euer Format" icon="document">
    Songs sind [ChordPro](https://www.chordpro.org/) – der offene Standard für
    Akkordblätter. Import einzeln oder als ZIP, PDF-Noten anhängen, eingebauter
    Editor mit Live-Vorschau.
  </Card>
  <Card title="Für Bands, Schulen und Kirchen" icon="star">
    Mehrere Bands einer Organisation teilen eine Song-Bibliothek. Mitglieder per
    Link oder QR-Code einladen. Rollen legen fest, wer Songs pflegt und Sets plant.
  </Card>
  <Card title="Eure Daten bleiben eure" icon="approve-check">
    setDING synchronisiert mit einem selbst betriebenen Server. Open Source unter
    der MIT-Lizenz.
  </Card>
</CardGrid>
