## Offline bereit

Ein Set ist offline bereit, wenn alle seine Songs und ihre PDF-Anhänge auf dem Gerät
sind. Dann brauchst du für den Auftritt kein WLAN mehr, und setDING zeigt beim Set
nichts an.

Fehlt etwas, steht in der Liste der Sets und im Set selbst zum Beispiel
**1 Song nicht offline**. Verbinde das Gerät mit dem Netz und warte, bis die
Synchronisation fertig ist, oder ziehe die Liste der Sets nach unten, um sofort zu
synchronisieren.

Damit die Sets auch **aktuell** sind, warnt setDING über den Sets, wenn

- der letzte Abgleich mit dem Server länger als einen Tag her ist (mit Datum und
  Zeit des letzten Abgleichs) oder dieses Gerät sich noch nie abgeglichen hat,
- Änderungen von diesem Gerät noch nicht auf dem Server sind, weil der letzte
  Abgleich fehlgeschlagen ist.

**Jetzt synchronisieren** in der Warnung gleicht sofort ab.

<Image src={offlineStatus} alt="Die Liste der Sets mit der Warnung, dass der letzte Abgleich mit dem Server zu lange her ist, und einem Set mit dem Hinweis «1 Song nicht offline»" />

Prüfe vor dem Auftritt auf jedem Gerät, dass weder eine Warnung noch ein
Hinweis beim Set steht.

## Set-Liste drucken

Im Menü ⋮ des Sets erstellt **Set-Liste exportieren (PDF zum Drucken)** eine
A4-Seite in grosser Schrift: Name, Datum und Ort des Sets, dann jeder Song mit
Nummer, Tonart und Songablauf, so wie die Band ihn in diesem Set spielt. Jeder
Hinweis – Pause, Ansage, Zugabe und so weiter – ist eine Trennlinie mit seinem Text
in der Mitte; so siehst du die Blöcke des Auftritts auf einen Blick. Speichere die Datei und drucke oder teile sie mit dem
PDF-Betrachter deines Geräts – zum Beispiel für das Mischpult oder die Bühnenkante.

<Image src={menu} alt="Das Menü ⋮ eines Sets mit den Exporten als PDF und ZIP" />

Sobald die Datei gespeichert ist, bietet die Meldung unten einige Sekunden lang
**Öffnen** an: Damit öffnet sich das PDF sofort in der Standard-App deines Geräts für
PDFs, bereit zum Drucken oder Teilen. Kann keine App auf dem Gerät PDFs öffnen, sagt
setDING das.

<Image src={pdfExported} alt="Die Meldung «Exportiert» mit der Aktion Öffnen nach dem PDF-Export" />

## Set exportieren

**Als ZIP exportieren** speichert das Set als ZIP-Archiv: jeden Song als
ChordPro-Datei, nummeriert in der Reihenfolge des Sets, dazu eine Beschreibung, mit
der setDING das Set wieder importiert – mit Hinweisen, Datum und Ort. Vor dem
Speichern wählst du, was ins Archiv kommt:

- **Band-Arrangements der Songs** – Tonart, Abfolge und Tempo der Band.
- **Tonart und Songablauf der Songs in diesem Set**.
- **Anhänge** – PDFs und Bilder der Songs.
- **Meine persönlichen Anpassungen und Notizen** – standardmässig aus. Lass das aus,
  wenn du die Datei weitergibst.

<Image src={exportDialog} alt="Der Dialog «Set exportieren» mit den Optionen für Band-Arrangements, Tonart und Songablauf in diesem Set, Anhänge und persönliche Anpassungen" />

Die ChordPro-Dateien lassen sich auch ohne setDING öffnen. So gibst du Songs auch an
jemanden weiter, der nicht in deiner Band ist. Für die Set-Liste allein nimmst du das
PDF weiter oben.

## Set importieren

Importiere das ZIP im Menü ⋮ der Set-Liste mit **Set importieren** oder mit
**Dateien importieren** in der Song-Liste. setDING erkennt ein exportiertes Set und zeigt,
was der Import tun wird, bevor sich etwas ändert:

- **Ziel** – die Band, in die das Set kommt.
- Songs, die es **schon gibt** mit gleichem Text, werden verwendet; **neue** Songs
  kommen in die Bibliothek. Für Songs, die es mit anderem Text gibt, wählst du
  einmal: die bestehenden behalten oder als zusätzliche Songs importieren.
- Fehlt einem Song, der schon da ist, ein **Anhang** aus dem Archiv, wird er
  ergänzt, sofern du den Song bearbeiten darfst.
- Gibt es das Set **schon in der Band** (du hast es dort exportiert oder früher
  importiert), bringt **Ersetzen** es auf den Stand des Archivs; das ist die Vorgabe.
  **Als Kopie hinzufügen** legt ein zweites an.
- Ein neu angelegtes Set behält seinen Namen, ausser die Band hat schon ein Set mit
  **gleichem Namen und Datum**: Dann heisst es «Sommerfest (Kopie)», «Sommerfest
  (Kopie 2)» und so weiter. Der Dialog zeigt den Namen vor dem Import.
- **Übernehmen** – dieselbe Auswahl wie beim Export, soweit das Archiv sie
  enthält. Band-Arrangements, die die Band schon hat, bleiben, ausser du kreuzt
  **Band-Arrangements überschreiben** an.
- In der **Setplanung** darfst du keine Songs in die Bibliothek aufnehmen: Songs, die
  dort fehlen, stehen im Set als Hinweis wie «Fehlt: Amazing Grace», und der Bericht
  listet sie auf. So kann sie jemand mit dem Recht dazu nachtragen.

<Image src={importDialog} alt="Der Dialog «Set importieren» mit den Abschnitten Ziel, Set schon vorhanden (Als Kopie gewählt, angelegt als «Sommerfest (Kopie)»), Songs und Übernehmen" />

Der Bericht danach zeigt, was importiert wurde; **Set öffnen** führt direkt hin.

<Image src={importResult} alt="Der Bericht «Set importiert»: das bestehende Set wurde ersetzt, ein Song importiert, einer war schon hier" />
