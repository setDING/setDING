## Offline ready

A set is offline ready when all its songs and their PDF attachments are on the
device. Then you do not need Wi-Fi for the gig any more, and setDING shows nothing
on the set.

If something is missing, the list of sets and the set itself say, for
example, **1 song not offline**. Connect the device to the network and wait until
the sync is done, or pull down the list of sets to sync right away.

So that the sets are also **up to date**, setDING shows a warning above the sets when

- the last sync with the server is more than a day ago (with the date and time of
  the last sync), or this device has never synced,
- changes from this device have not reached the server because the last sync
  failed.

**Sync now** in the warning syncs right away.

<Image src={offlineStatus} alt="The list of sets with the warning that the last sync with the server is too long ago, and a set saying “1 song not offline”" />

Before the gig, check on every device that there is no warning and no note on
the set.

## Share a link to a set

In a set's ⋮ menu, **Share link** shares a link to the set, in the band's chat for
example. On a phone or tablet, your device's share menu opens; on a computer and in
the browser, setDING copies the link, and you paste it into the chat. A song's
menu has **Share link** in the same way.

<Image src={shareLink} alt="The ⋮ menu of a set with the entry Share link" />

Whoever opens the link goes straight to the set:

- **setDING installed** (Android): the app opens at the set. If it belongs to a
  band other than the chosen one, setDING switches to that band and says so.
- **Otherwise** the set opens in the browser, in setDING on the web. Whoever is not
  signed in there signs in first and then gets to the set.

The link tells nothing about the set, not even its name. It gives no rights: only
the band's members and the people planned for the set can see it.

If the set is not on the device yet, setDING shows **Not available on this
device**. **Sync now** fetches it; as soon as it arrives, it opens. If it is still
missing after that, it was deleted, or you have no access to it.

<Image src={notAvailable} alt="The page «Not available on this device» saying the set is not synced yet or there is no access, with the button Sync now" />

In the browser, every page of setDING has its own address: the browser's **Back**
and **Forward** go through the app's pages, and a page stays open when you reload.

## Print the set list

In the set's ⋮ menu, **Export …** opens the export dialog. The format **Set list as
PDF** creates an A4 page in
large type: the set's name, date and venue, then every song with its number, key and
song sequence, as the band plays it in this set. Every marker – break, announcement,
encore and so on – is a divider line with its text in the middle, so the blocks of the
show stand out at a glance.
Save the file and print or share it with your device's PDF viewer – for the mixing
desk or the edge of the stage, for example.

<Image src={menu} alt="The ⋮ menu of a set with the entry Export …" />

Once the file is saved, the message at the bottom offers **Open** for a few seconds:
it opens the PDF straight away in your device's default app for PDFs, ready to print
or share. If no app on the device can open PDFs, setDING says so.

<Image src={pdfExported} alt="The message “Exported” with the action Open after the PDF export" />

## Export a set

The format **setDING archive (ZIP)** in the same dialog saves the set as a ZIP archive: every song as a ChordPro file,
numbered in the order of the set, and a description from which setDING imports the
set again – with its markers, date and venue. For the archive, choose what goes
into it; the format chosen last is preselected the next time:

- **Band arrangements of the songs** – the band's key, sequence and tempo.
- **Key and sequence of the songs in this set**.
- **Attachments** – PDFs and images of the songs.
- **My personal adjustments and notes** – off by default. Leave it off if you pass
  the file on.

<Image src={exportDialog} alt="The dialog «Export set» with the format setDING archive and the options for band arrangements, key and sequence in this set, attachments and personal adjustments" />

The ChordPro files can be opened without setDING too, so the archive also serves to
pass songs on to someone outside your band. For the set list on its own, use the
format Set list as PDF.

In the browser, exporting works the same way: the file goes to your downloads.

## Import a set

Import the ZIP with **New set** → **Import from file …**, or with **Import files** in
the song list.

<Image src={newSetImport} alt="The dialog New set with Import from file … below the date" />

setDING recognises an exported set and shows what the import will do
before anything changes:

- **Destination** – the band the set goes to.
- Songs that are **already here** with the same text are used as they are; **new**
  songs are added to the library. For songs that exist with a different text you
  choose once: keep the existing ones or import them as additional songs.
- If a song that is already here lacks an **attachment** from the archive, it is
  added, provided you may edit the song.
- If the set is **already in the band** (you exported it from there, or imported it
  before), **Replace it** brings it to the state of the archive; that is the default.
  **Add as a copy** adds a second one.
- An added set keeps its name unless the band already has a set with the **same
  name and date**: then it is called «Summer party (copy)», «Summer party (copy 2)»
  and so on. The dialog shows the name before you import.
- **Include** – the same choices as for the export, as far as the archive holds
  them. Band arrangements that the band already has stay as they are unless you tick
  **Overwrite the band's arrangements**.
- As a **set planner** you may not add songs to the library: songs that are missing
  there become markers such as «Missing: Amazing Grace» in the set, and the report
  lists them, so someone with the right can add them.

<Image src={importDialog} alt="The dialog «Import set» with the sections Destination, Set already here (Add as a copy chosen, added as «Summer party (copy)»), Songs and Include" />

The report afterwards shows what was imported, with **Open set** to go straight to
it.

<Image src={importResult} alt="The report «Set imported»: the existing set was replaced, one song imported, one already here" />
